CODEX + CLAUDE CODE

A small skill.
A plain-language request.

From a local checkout of the repository, install into your site's project. Python 3.9+ is the only requirement for these tools.

FROM THE AI DISCLOSURE REPOSITORY
python3 scripts/install.py \
  --project /path/to/your-site
THEN ASK YOUR CODING AGENT
“Fix this site's AI disclosure requirements with the least intrusive appropriate notices. Use ai-disclosure and verify the result.”

Installs the same skill for both agents. Nothing is published, and global settings stay unchanged.

CLEAR ABOUT WHAT IT COVERS

Transparency tools.
With their own transparency.

Available in this preview

  • Portable coding-agent skill and local installer
  • Evidence-based publisher assessment input
  • Static article and image disclosure rendering
  • Content-version checks and review invalidation

Still being completed

  • Audio/video and live-chat integrations
  • Dynamic publishing adapters and export checks
  • Public release and independent legal review

AI Disclosure supports AI Act transparency work. It does not detect every AI asset, certify legal compliance, or replace requirements concerning privacy, copyright and misleading content. An installed skill needs a publishing integration to handle future content automatically.
