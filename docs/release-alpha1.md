# AI Disclosure 0.1.0-alpha.1

A development release for pilot integrations. One minimal skill supports Codex and Claude Code, with local assessment, version-bound content records and HTML publishing tools.

Included: article/image notices, chat interaction wrappers, experimental local audio/video controls with captions and spoken-notice sequencing, immutable output staging, a project installer and reproducible skill/plugin archives.

The toolkit evaluates declared facts. It does not detect AI authorship, authenticate editorial review, certify compliance or cover every site/product structure. Future content requires publishing integration. General runtime/CMS adapters, direct asset/export handling, provider marking and independent legal review remain incomplete. No official marketplace endorsement or listing is claimed.

Validation: Python tests on Linux/macOS and Chromium checks for article/image rendering, chat deep links, media sequencing, captions and fullscreen. The plugin manifests also passed local Codex schema and Claude strict validation. Media fixtures test mechanics, not legal adequacy of spoken wording.

Download either the standalone skill or the dual-host plugin archive, with SHA256SUMS. See the repository's distribution guide for installation and scope.
