# AI Disclosure 0.1.0-alpha.3

Candidate release notes. Publication is pending verification of the exact release commit. This remains a development prerelease, not a production-compliance claim. The catalog currently installs alpha.2 until its versioned archive is explicitly updated and verified.

## Changes from alpha.2

- A dependency-free Node publishing client calls the bundled Python engine during publication and holds unresolved updates. The repository includes a runnable Next.js static-export example.
- Portable article/image HTML exports embed original raster bytes and retain notices offline and in print styling. Raw media, PDF/Word and native/social exports remain separate integration work.
- An experimental WordPress text plugin records private version-bound facts, renders notices on supported text surfaces and gates supported publication paths. It includes classic/block editor controls, amendments, draft withdrawal and a WP Super Cache adapter for the tested configuration.
- Repository-only WordPress migration tooling provides bounded, resumable discovery, read-only planning and explicit evidence-backed apply with revision preconditions. It never guesses historical origin or publishes drafts.
- The installed skill's existing publishing reference points agents to the supported integrations. Its five-step entrypoint is unchanged.
- CI exercises WordPress on SQLite and MySQL, with Chromium, Firefox and WebKit. A previously observed Firefox login timeout remains unexplained; failure diagnostics were added without retries or changed timeouts. A later diagnostic run passed its MySQL job, which does not establish that the intermittent issue is fixed.

## Choose the appropriate archive

| Archive | Destination |
| --- | --- |
| `ai-disclosure-skill.zip` | Project skill directory for Codex or Claude Code. |
| `ai-disclosure-plugin.zip` | The tested host plugin loader; one shared skill plus host manifests. |
| `ai-disclosure-wordpress.zip` | An isolated WordPress integration test site. Activation adds publication gates and can interrupt workflows without recorded facts. |

The migration CLI, Next.js example, tests and website stay in the source repository. Installing an agent archive does not activate the WordPress plugin. Installing the WordPress plugin does not install an agent skill, discover content origins or set up every future publishing job.

Compare each archive with the release's `SHA256SUMS`. Keep the migration client and PHP plugin on matching policy versions. Review existing installations before replacing files; the project installer preserves differing local skills. Back up WordPress records and plugin files, follow the documented replacement workflow, and verify actual rendered surfaces and caches before resuming publication.

## Remaining release gates

Independent legal review and representative customer deployments are outstanding. Unsupported modalities and publishing surfaces stay explicit. The product neither certifies compliance nor establishes unknown facts. A blanket “may contain AI” banner is not implemented as a substitute for appropriate notices. See the release audit and legal review package for the full outstanding scope.
